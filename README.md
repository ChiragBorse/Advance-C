# 🚀 Advance-C

A collection of **Advanced C Programming** concepts, programs, and practical implementations designed to strengthen problem-solving skills and understanding of core C programming.

This repository contains programs covering advanced concepts such as pointers, structures, functions, arrays, strings, dynamic memory allocation, file handling, and other important C programming techniques.

---

## 📌 About The Repository

**Advance-C** is a learning-focused C programming repository created to practice and demonstrate concepts beyond basic C syntax.

The goal is to build a strong foundation in C programming while understanding how memory, pointers, data structures, and system-level programming concepts work.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/ChiragBorse/Advance-C.git
```

### 2. Navigate into the project

```bash
cd Advance-C
```

### 3. Compile a C program

```bash
gcc filename.c -o program
```

### 4. Run the program

**Windows:**

```bash
program.exe
```

**Linux / macOS:**

```bash
./program
```
